# INKVERSE — Tattoo Studio Demo

Public demo site for a tattoo studio: gallery, booking, custom design requests, customer accounts, and an admin dashboard.

## Live deploy

This repository is connected to Vercel after the first successful deploy.

## Local development

```bash
npm install
npm run dev
```

App runs on `http://localhost:8080`.

## Demo admin

- Admin URL: `/admin/login`
- Demo email: `demo@inkverse.com`
- Use the **Enter Demo Admin** button on a fresh database to create the demo admin account.

## Stack

- Vite + TanStack Start + React
- Tailwind CSS
- PGLite / Postgres migrations
- Vercel-ready (`vercel.json`)
